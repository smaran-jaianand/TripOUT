# Event Planner AI - React + Vite Application

This is a React + Vite application that implements the Event Planner UI design based on the provided HTML templates.

## Features

- Responsive design using Tailwind CSS
- Material Symbols icons for a modern UI
- Custom color scheme and typography based on the Verdant Professional Design System
- Interactive navigation sidebar
- Event planning workspace with AI-generated options
- Fully functional React components

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser to http://localhost:5173

## Project Structure

- `src/App.jsx` - Main application component
- `src/index.css` - Global styles and Tailwind configuration
- `tailwind.config.js` - Tailwind CSS configuration with custom colors and fonts
- `postcss.config.js` - PostCSS configuration

## Design Elements

The application implements the Verdant Professional Design System with:
- Nature-inspired color palette
- EB Garamond for headlines
- Noto Serif for body text
- Manrope for labels and UI elements
- Moderate rounded corners
- Clean, professional layout
